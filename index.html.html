How To Run It — 1 Cycles, Back To Back

Do this exact 2-load sequence once per brick. Each full cycle uses 350 leaves + 7 cement and yields exactly 100 Coca Blends — precisely one brick's worth.

Add 4 batches of 50 leaves (200 total) to the box. Add 3 cement — only enough for the top 3 batches. This yields 45 Coca Blends. Leave the bottom batch (50 leaves) un-cemented.
Add 3 more batches of 50 leaves (150 total) on top of the untouched bottom layer. Add 3 cement for those new top batches, plus 1 more cement to finally close out the original bottom layer. This yields 55 Coca Blends in one step.
You now have exactly 100 Coca Blends (45 + 55). Convert all of it: 100 blends + 10 gasoline → 20 coca paste → + 20 acid → 20 coke → 1 full brick.
Repeat this entire 2-load sequence from scratch for every additional brick. Never carry a "half-finished" bottom layer between bricks — closing it out fully every cycle is what keeps the math clean.
Why this beats stretching batches across a long session: the only way to get the "bonus" 55-blend load is to close the bottom layer with 1 extra cement. Closing it every 2 loads (once per brick) uses that bonus efficiently every time. Stretching it across a longer run only gets you that bonus once, forcing extra loads elsewhere and leaving awkward leftovers.
